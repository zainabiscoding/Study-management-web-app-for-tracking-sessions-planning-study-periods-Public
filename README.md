# Personal Study Tracker

A personal study management web app for tracking study sessions, planning study periods, managing reminders, and storing data using Local Storage.

## Features

- Study session timer
- Start, pause, and resume sessions
- Study session history
- Daily study time tracking
- Study streak tracking
- Pomodoro timer
- Study plans and reminders
- Monthly calendar
- Add, edit, and delete study plans
- Subject management
- Arabic and English language support
- Local Storage for saving data

## Technologies

- HTML
- CSS
- JavaScript
- Local Storage

## Project Structure

- `index.html` — Main dashboard
- `script.js` — Study timer and session management
- `previous-sessions.html` — Previous study sessions
- `previous-sessions.js` — Session history logic
- `plans.html` — Study plans and reminders
- `plans.js` — Plans and calendar logic
- `settings.html` — Application settings
- `settings.js` — Settings and subject management
- `style.css` — Application styling

## Data Storage

The application uses browser Local Storage to save study sessions, subjects, study plans, reminders, and language preferences.
